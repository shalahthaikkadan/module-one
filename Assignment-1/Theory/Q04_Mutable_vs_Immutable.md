What is the difference between mutable and immutable data types?

Answer
-------

Mutable
---------
Mutable objects can be changed after creation

eg: list,dictionary,set

```python
my_list = [1, 2, 3]
my_list[0] = 10
```

immutable
---------
Cannot be changed after creation

eg:tuple,int,float

```python
name = "Python"
name[0] = "J"
```
